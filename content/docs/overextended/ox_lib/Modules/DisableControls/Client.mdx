Uma forma centralizada de rastrear e desabilitar [controles do jogo](https://docs.fivem.net/docs/game-references/controls/#controls).

## lib.disableControls

Chame a cada frame para desabilitar todos os controles armazenados.

```lua
lib.disableControls()
```

## lib.disableControls:Add

Adiciona o(s) controle(s) especificado(s) à lista armazenada.  
Se o controle já estiver sendo rastreado, o contador armazenado será incrementado.

```lua
lib.disableControls:Add(...)
```

- vararg: `number` ou `number[]`
  - Controle(s) para adicionar uma contagem armazenada

## lib.disableControls:Remove

Remove o(s) controle(s) especificado(s) da lista armazenada.  
Se o contador armazenado para um determinado controle for maior que um, o contador armazenado será decrementado.

```lua
lib.disableControls:Remove(...)
```

- vararg: `number` ou `number[]`
  - Controle(s) para remover uma contagem armazenada

## lib.disableControls:Clear

Limpa o(s) contador(es) armazenado(s) para o(s) controle(s) especificado(s).

```lua
lib.disableControls:Clear(...)
```

- vararg: `number` ou `number[]`
  - Controle(s) para limpar do rastreamento
