## lib.getFilesInDirectory

Obtém uma lista de todos os arquivos em um diretório de resource especificado, junto com a contagem de arquivos

```lua
lib.getFilesInDirectory(path, pattern)
```

- path: `string`
  - O caminho relativo ou absoluto para o diretório onde os arquivos devem ser listados.
- pattern: `string`
  - Padrão a ser verificado ao procurar arquivos.

Retorno:

- files: `string[]`
- fileCount: `number`
