Um sistema de verificação espacial de alta performance para o mundo do jogo. Zones definem uma área 3D (sphere, box ou polygon) e avaliam se uma posição está dentro ou fora daquela região — semelhante a um [colshape](https://wiki.multitheftauto.com/wiki/Element/Collision_shape).

Internamente, as Zones utilizam um [spatial grid](docs/ox_lib/Grid/Shared) para restringir com eficiência as zones relevantes antes de executar testes precisos de posição.

Para Lua, isto substitui o [PolyZone](https://github.com/mkafrin/PolyZone) e aproveita a biblioteca [GLM](https://github.com/citizenfx/lua/blob/luaglm-dev/cfx/README.md) para alta performance e eficiência de memória.

As Zones também estão disponíveis em JS, utilizando nossa [biblioteca de utilidades](https://github.com/overextended/ox) para operações de geometria, grid e espaciais.

<Callout>
  Zones do lado do servidor não suportam eventos de trigger do jogador. Os manipuladores `onEnter`, `onExit` e `inside` estão indisponíveis.
</Callout>

<Callout>
  As zones em Lua e JavaScript não são compatíveis em termos de API. As definições TypeScript e os comentários TSDoc no pacote npm servem como referência oficial para a JavaScript API.
</Callout>

## Polygon/Prism Zone

Cria um polígono a partir dos vértices fornecidos, que é então colocado no mundo e extrudado até a altura fornecida para formar uma forma 3D.

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua
lib.zones.poly(data)
```
- data: `table`
  - points: `vector3[]`
    - Um array de pontos 3D que definem a forma do polígono.
  - thickness?: `number`
    - A altura do polígono, padrão `4`.
  - onEnter?: `function(self: table)`
  - onExit?: `function(self: table)`
  - inside?: `function(self: table)`
  - debug?: `boolean`
</Tab>
<Tab>
```ts
import { Zone } from "@overextended/ox_lib";
import { Vector2 } from "@overextended/core/vector";

Zone.Prism(vertices: Vector2[], height: number, z: number)
```
</Tab>
</Tabs>

## Box Zone

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua
lib.zones.box(data)
```
- data: `table`
  - coords: `vector3`
  - size?: `vector3`
    - Padrão: `vec3(2, 2, 2)`
  - rotation?: `number`
    - Ângulo em graus, padrão `0`.
  - onEnter?: `function(self: table)`
  - onExit?: `function(self: table)`
  - inside?: `function(self: table)`
  - debug?: `boolean`
</Tab>
<Tab>
```ts
import { Zone } from "@overextended/ox_lib";
import { Vector3 } from "@overextended/core/vector";

Zone.Cuboid(origin: Vector3, width: number, depth: number, height: number, heading?: number)
```
</Tab>
</Tabs>

## Methods

### onEnter

Uma função chamada quando o jogador entra na zone. Ela pode ser anexada à zone após a instanciação, ou na tabela `data` se estiver usando Lua.

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua
local function onEnter(self)
    print('entered zone', self.id)
end

zone.onEnter = onEnter
```
</Tab>
<Tab>
```ts
function onEnter(this: Zone) {
  console.log(`entered zone ${this.id}`)
}

zone.onEnter = onEnter;
```
</Tab>
</Tabs>

### onExit

Uma função chamada quando o jogador sai da zone. Ela pode ser anexada à zone após a instanciação, ou na tabela `data` se estiver usando Lua.

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua
local function onExit(self)
    print('exited zone', self.id)

zone.onExit = onExit
```
</Tab>
<Tab>
```ts
function onExit(this: Zone) {
```

</Tab>
</Tabs>

Uma função chamada quando o jogador sai da zone. Ela pode ser anexada à zone após a instanciação, ou na tabela `data` se estiver usando Lua.

### remove

Zones podem ser excluídas usando o método remove.

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua

```
</Tab>
<Tab>
```ts
zone.remove()
// or

```
</Tab>
</Tabs>

### contains

Avalia se um ponto está dentro da zone.

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua
zone:contains(vec3(1, 1, 1))
```
</Tab>
<Tab>
```ts
import { Vector3 } from "@overextended/ox_lib";

zone.contains(new Vector3(1, 1, 1))
```
</Tab>
</Tabs>

**Retorna:** `boolean`

### setDebug

Ativa ou desativa o modo debug para uma zone, opcionalmente com cores personalizadas.

Para JavaScript, defina `zone.shouldDraw` ou chame manualmente `zone.draw(...args)`.

```lua
local zone = lib.zones.box({...})

-- Enable debug with default colors
zone:setDebug(true)

-- Enable debug with custom colors
zone:setDebug(true, vec4(255, 0, 0, 100))

-- Disable debug
zone:setDebug(false)
```

## Zone creation script

Você pode usar nosso criador de zones embutido com `/zone` — passando `poly`, `box` ou `sphere` como argumento.
Os controles disponíveis serão exibidos no lado direito.

As zones serão salvas em `ox_lib/created_zones.lua` no formato escolhido.
