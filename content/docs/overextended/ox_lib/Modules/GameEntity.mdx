## Métodos de GameEntity

### set

Escreve um valor na statebag da entidade.

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua
entity:set(key, value)
```
</Tab>
<Tab>
```ts
entity.set(key, value)
```
</Tab>
</Tabs>

- key: `string`
- value: `any`

**Retorna:** `boolean` - Se o estado mudou.

### setr

Escreve um valor replicado na statebag da entidade. Valores definidos no cliente são validados pelo servidor (veja [Hooks](./Hooks#registered-hooks)).  
Valores replicados são sincronizados entre o servidor e todos os jogadores relevantes.

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua
entity:setr(key, value)
```
</Tab>
<Tab>
```ts
entity.setr(key, value)
```
</Tab>
</Tabs>

- key: `string`
- value: `any`

**Retorna:** `boolean` - Se o estado mudou.

### sets

Escreve um valor sincronizado na statebag da entidade. Valores definidos no cliente são validados pelo servidor (veja [Hooks](./Hooks#registered-hooks)).  
Valores sincronizados são replicados apenas entre o jogador e o servidor, e não podem ser definidos em entidades que não sejam de jogador.

<Tabs groupId="language" items={['Lua', 'TypeScript']}>
<Tab>
```lua
entity:sets(key, value)
```
</Tab>
<Tab>
```ts
entity.sets(key, value)
```
</Tab>
</Tabs>

- key: `string`
- value: `any`

**Retorna:** `boolean` - Se o estado mudou.
